# 🚛 Truck Fleet Management Project

A multi-language demo project inspired by truck logistics and fleet systems.

## Features
- Truck movement simulation (Python)
- Fleet controller (JavaScript)
- Web dashboard (HTML/CSS)
- Simple API server (Node.js)
- Load engine (C++)
- Truck model (Java)
- Fuel consumption calculator (Go)
- Diagnostics tool (Rust)
- Configuration files (JSON & YAML)

Drive your logistics system with code.
